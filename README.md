# 🐍 Classic Snake Game

A browser-based implementation of the classic Snake Game built using web technologies. Control the snake, eat food to grow, and try to achieve the highest score without colliding with the walls or yourself!

## 🚀 Live Demo

Check out the live deployment here:  
👉 [Play Snake Game Live](https://maxwel12744.github.io/Snake-game/)[cite: 2]

## 🛠️ Built With

* **HTML5** – Structures the game layout and canvas/display element.
* **CSS3** – Handles the page styling, game frame, and visual presentation[cite: 2].
* **JavaScript (ES6+)** – Powers the game engine, movement logic, collision detection, and score tracking[cite: 2].

## 🎮 How to Play

1. Open the game in any modern web browser.
2. Use the **Arrow Keys** (or **W, A, S, D** depending on implementation) to control the snake's movement direction.
3. Eat the food appearing on the screen to score points and grow longer.
4. Avoid running into the borders or the snake's own body!
